# Air Canvas 🎨✋

Air Canvas is a computer vision–based application that allows users to draw on the screen using hand gestures, without touching any physical device.

## 🚀 Features
- Real-time hand tracking using webcam
- Gesture-based drawing
- No mouse or touchscreen required

## 🛠 Tech Stack
- Python
- OpenCV
- MediaPipe

## ▶️ How to Run
1. Clone the repository
2. Create a virtual environment
3. Install dependencies
4. Run the main script

## 📌 Use Case
Interactive drawing, touchless interfaces, and gesture-based HCI experiments.
